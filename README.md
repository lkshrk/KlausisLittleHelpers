# LKS_UI

Opt-in additions to [EllesmereUI](https://github.com/EllesmereGaming/EllesmereUI), shown as an "LKS UI" section in the EllesmereUI options panel. Requires EllesmereUI. Runs on retail and WoW Forever.

Open it with `/lks` (or `/lksui`). Every feature starts off; turning one on or off takes effect after a reload. Settings follow the active EllesmereUI profile.

Development notes are in [AGENTS.md](AGENTS.md).
