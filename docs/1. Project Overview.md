# Project Overview

## What is Klausi's Little Helpers?

Klausi's Little Helpers (KLH) is a World of Warcraft addon in the folder `KlausisLittleHelpers`. It bundles a few small, independent helpers for questing, travel routes and professions. The addon is written in Lua 5.1 and loads on two clients:

- **WoW Forever** (interface 16001, build numbers 16000 to 19999).
- **Retail** (interface 12.x: 120000, 120001, 120005, 120007, 120100, 120105).

The addon is standalone. It carries its own Ace3 libraries in `Libs/` and has no hard dependency on another addon. Each feature declares which other addons it needs, and stays off (with a greyed "Requires" section in the options) when they are missing.

## Core Purpose

Give the player small quality-of-life tools that other addons do not provide, without forcing a full UI suite. Each feature loads only on the clients it supports, and only when the addons it extends are present.

## Features and Clients

| Feature (registry key) | Title in options | Clients | Required addons | Optional addons |
|---|---|---|---|---|
| `TustUIXPBar` | TustUI Enhanced XP Bar | Retail and Forever | `Tust_EUI`, `EllesmereUI` | none |
| `QuestieRXPSync` | RestedXP Quest Sync | Forever | `RXPGuides` | `Questie` |
| `TurnInRoute` | Turn-in Route | Forever | `Questie` | `TomTom` |
| `WritCratePlanner` | Writ & Crate Planner | Forever | `Auctionator` | none |
| `SoulstoneReminder` | Soulstone Reminder | Forever | none | none |
| `LayerPrompt` | Layer Change Prompt | Forever | none | none |
| `MinimapButton` | Minimap Button | Retail and Forever | none | none |
| `FarmTracker` | Farm Tracker | Retail and Forever | none | none |

What each one does:

- **TustUI Enhanced XP Bar** adds session XP and an all-time XP/hour rate (saved per character) to TustUI's XP bar texts.
- **RestedXP Quest Sync** makes your quest tracker (Questie's, or the default one) show only the quests of your current RestedXP guide, and untracks the rest.
- **Turn-in Route** adds a world map button. It plans the fastest route to every quest and writ that is ready to turn in, using flight paths, ships, zeppelins, an optional hearthstone and optional mage teleports. It draws numbered markers and lines on the world map and adds TomTom waypoints when TomTom is loaded.
- **Writ & Crate Planner** plans the cheapest Craftsman's Writs and Waylaid Crates for a reputation or Merchant's Favor target, using Auctionator prices, and writes the plan as an Auctionator shopping list. Two macros apply Forged Delivery Receipts and fill crates one press at a time. It also learns real reputation values from your turn-ins.
- **Soulstone Reminder** warns in dungeons and raids, out of combat, when a warlock's soulstone is ready and no Priest, Paladin, Shaman or Druid carries one: a movable banner, and optionally a group announcement, a whisper to the warlock and a sound.
- **Minimap Button** opens settings and the helpers menu from the minimap or addon compartment.
- **Farm Tracker** tracks fishing and manual farming sessions and shared area history.
- **Layer Change Prompt** moves Blizzard's layer change prompt (`ShardTransferImminentFrame`, click it to change layer now) to a draggable, saved spot at strata DIALOG. Blizzard anchors it above the chat, where chat addons can hide it: TustUI parks `ChatFrame1ButtonFrame` off screen unless its chat menu is on.

Six features (`TustUIXPBar`, `TurnInRoute`, `WritCratePlanner`, `LayerPrompt`, `MinimapButton`, `FarmTracker`) are registered with `alwaysOn = true` and have no Enable toggle. RestedXP Quest Sync (`QuestieRXPSync`) and Soulstone Reminder (`SoulstoneReminder`) are not `alwaysOn`: each has an Enable toggle and starts off. RestedXP Quest Sync asks for a reload when switched; Soulstone Reminder declares `disable` and switches live.

## Technology Stack

- **Language**: Lua 5.1 (the WoW client runtime). Helper scripts use Bash and Python 3.
- **Libraries (fetched into `Libs/` from `.pkgmeta` by `scripts/libs.sh`)**: LibStub, CallbackHandler-1.0, AceEvent-3.0, AceDB-3.0, AceDBOptions-3.0, LibDataBroker-1.1, LibDBIcon-1.0. They are loaded through `Libs/embeds.xml`.
- **Borrowed at runtime from other addons**: HereBeDragons (route planner), Krowi_WorldMapButtons-1.4 (map button), QuestieLoader modules, TomTom, Auctionator API v1.
- **Build and packaging**: BigWigs packager, driven by `.pkgmeta` (`package-as: KlausisLittleHelpers`).
- **Quality tooling**: `luac5.1 -p`, `luacheck` (`.luacheckrc`), a plain-Lua test runner (`.tools/tests/run.lua`), `lefthook`, `gitleaks`, `shellcheck`, `actionlint`.
- **CI**: GitHub Actions (`check.yml`, `release.yml`).
- **Dependency updates**: Renovate (`renovate.json5`).

## Getting Started

### Install for development

The repository root is the addon folder. `scripts/sync.sh` copies it into the live game folders with `rsync`:

```sh
scripts/sync.sh forever --dry-run   # preview
scripts/sync.sh forever             # or retail, or all
```

Then type `/reload` in the game. The script uses `WOW_DIR` (default `/mnt/stuff/Games/World of Warcraft`) and replaces `@project-version@` in the copied TOC with a version taken from git. See [Tooling and Tests](<4. Deep Dive/Tooling and Tests.md>).

### Open the options

- Type `/klh`. With no argument it opens the settings window.
- Or open the Blizzard Settings window, go to AddOns, pick "Klausi's Little Helpers" and press "Open Klausi's Little Helpers". The settings panel closes first.
- The sidebar lists feature pages by category; features with a `section` share a page under header lines.
- `/klh writs` opens the Writ & Crate Planner at the auction house, explains the restriction elsewhere, and closes an already open window (needs Auctionator).
- `/klh writs macros` works anywhere and makes the general macros "KLH Receipt" and "KLH Fill Crate" and opens the macro window.
- A wrong subcommand prints the list of known commands. A command of a feature whose addons are missing prints "Requires: ...".

### Use the features

- Turn-in Route: open the world map and click the checkmark button. Right-click it for a source menu (Plan all, one entry per source, and Abort route while a route is active).
- Writ & Crate Planner: open the Auction House and click "Writ Planner" beside it, or use `/klh writs`.
- Soulstone Reminder: turn on "Enable Soulstone Reminder" in the QoL tab (Dungeons & Raids); no reload needed.
- RestedXP Quest Sync: turn on "Enable RestedXP Quest Sync" in its options page and reload. The XP bar works on its own once Tust_EUI and EllesmereUI are loaded.

### Develop

```sh
scripts/check.sh   # compile, TOC coverage, tests, luacheck, ASCII check
scripts/test.sh    # only the tests
lefthook install   # once per clone
```

The development flow (check, test, sync, errors, release) is in [CONTRIBUTING.md](../CONTRIBUTING.md).

## Architecture Summary

A small core (`Core/Core.lua`) holds a feature registry. Each feature file in `Modules/` registers one feature with a spec table (key, title, `tab`, optional `section`, required and optional addons, defaults, `enable`, optional `disable`, `options`). A central table, `ns.FEATURE_CLIENTS`, decides which client loads which feature. At `PLAYER_LOGIN` the core enables each feature whose client matches and whose required addons are loaded. Settings live in an AceDB profile inside `KLH_Store.database`; per-character learned data lives in AceDB `db.char`. Version 0 starts fresh and does not import `KLH_DB` or `KLH_CharDB`. Algorithmic code (route graph, writ search, candidate building) is kept in pure modules that the test runner loads outside the game.

Details: [Architecture Overview](<2. Architecture Overview.md>), [Workflow Overview](<3. Workflow Overview.md>) and the files in `4. Deep Dive/`.
